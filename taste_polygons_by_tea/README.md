# Вкусовые многоугольники по чаям

Одна картинка = один чай. Имена пользователей не подписаны; пользователи отмечены разными цветами и звёздочками.

Учитываются только пользователи, у которых для данного чая заполнено минимум 3 вкусовых критерия.

- Чай 1: пользователей с 3+ критериями — 2
- Чай 2: пользователей с 3+ критериями — 4
- Чай 3: пользователей с 3+ критериями — 0
- Чай 4: пользователей с 3+ критериями — 0
- Чай 5: пользователей с 3+ критериями — 1
